RC71 V6.1.4 PDF PWA — iPad Safari + Chrome

1. Upload this folder to an HTTPS web host. Do NOT open index.html directly from Files.
2. Open the HTTPS address in Safari or Chrome on iPad.
3. Safari/iPadOS 26: Share -> Add to Home Screen -> keep “Open as Web App” enabled -> Add.
4. Chrome iPad: Share -> Add to Home Screen -> Add.
5. Open the RC71 icon from the Home Screen.

PDF Teleprompter uses the original PDF rendering and keeps the PDF’s original colors/layout.
The first use of PDF Visual Teleprompter requires internet access to load PDF.js if it is not already cached.
